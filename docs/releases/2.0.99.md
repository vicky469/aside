# 2.0.99

## What's new

- Keep public publishing hidden behind the default-off publish feature flag until it is explicitly enabled from the CLI.
- Show the current note at the top of tag-based Thought Trail results and mark it as current without making it clickable.
- Render tag-based Thought Trail related files as a compact flush list instead of card-like rows.
- Fix pinned sidebar navigation so clicking a card opens the matching source location when multiple files are open.

## Notes

- No user migration is required.
- Release artifacts remain limited to `main.js`, `manifest.json`, and `styles.css`.
