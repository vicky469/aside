# 2.0.102

## What's new

- Run `@deepseek` through your configured OpenCode CLI while keeping model selection, credentials, and permissions owned by OpenCode.
- Create and update registered vault scripts with the selected default agent, including isolated script tests and explicit renames only when the request asks for one.
- Convert PDFs to Markdown from the agent command flow, with protected destinations and clearer progress, recovery, and failure feedback.
- Add page notes and regenerate agent replies in supported file-backed views, including PDFs and other non-Markdown files.
- Publish HTML with recursively resolved local CSS, images, and other referenced site assets.
- Filter overlapping Thought Trail tags without duplicate file rows, keep slash-menu keyboard selection stable, and share comments while editing.
- Keep cancelled agent cards removable: edit and delete actions return immediately while the `Cancelled` status remains visible for 30 seconds.

## Notes

- Agent-backed commands are experimental and disabled by default per vault. To enable them, open Obsidian Developer Tools → Console and run:

  ```js
  localStorage.setItem(`aside.feature.agents.${app.vault.getName()}`, "true");
  await app.plugins.disablePlugin("aside");
  await app.plugins.enablePlugin("aside");
  ```

- Aside does not pass a model override to OpenCode; `@deepseek` inherits the model currently configured there.
- Existing script names are preserved unless an update request explicitly asks to rename the script and slash command.
- No data migration is required.
- Release artifacts remain limited to `main.js`, `manifest.json`, and `styles.css`.
