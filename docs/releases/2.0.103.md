# 2.0.103

## What's new

- Run Cursor as a supported peer alongside Codex, Claude, Gemini, and OpenCode-managed agents, with shared progress streaming and useful failure cards across providers.
- See the reply card immediately after saving an agent prompt, with a smooth turning status, concise gray progress, and formatted output as soon as the response arrives.
- Run multiple agents concurrently without duplicate cards, cross-run interference, unwanted source-note scrolling, or regeneration leaving stale replies behind.
- Keep replies durable through overlapping saves, note renames, cancellation, post-save refreshes, and delayed persistence without falsely reporting that a saved reply failed.
- Explore Thought Trail attachments with content-aware source defaults and compact, left-aligned filenames.
- Protect private information with redacted runtime diagnostics, bounded prompt context, a bundled agent-writing rule, and a compliance check for personal paths in tracked artifacts.

## Notes

- Agent-backed commands remain experimental and disabled by default per vault.
- Local agent CLIs, accounts, models, credentials, and usage limits remain user-managed; Aside does not bundle third-party agent runtimes.
- No data migration is required.
- Release artifacts remain limited to `main.js`, `manifest.json`, and `styles.css`.
