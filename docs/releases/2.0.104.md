# Release Highlights

Faster Index startup, better search, and a quieter default experience.

## Highlights

- Open the Index sidebar on List by default. Todo shows a loading indicator while data loads, then updates automatically without switching tabs.
- Search tags across notes with fuzzy matching, tag filters, and deduplicated file results. Search global Todos or replies in a selected file using the shared sidebar controls.
- Keep Scripts and Publishing disabled by default, with their settings hidden until enabled in Advanced.
- Improve draft stability, reply ordering, sync handling, and recovery from interrupted agent runs or publishing failures.
- Refresh settings with an animated bunny and rotating Thought Trail graph, while reducing the production bundle size.

## Notes

- Agent workflows require a locally installed agent CLI and user-managed accounts and credentials.
- Release assets are limited to `main.js`, `manifest.json`, and `styles.css`.
