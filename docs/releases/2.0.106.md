# Release Highlights

Fix sync bookkeeping that could leave Aside comments and replies missing even after their Markdown notes had synced.

## Highlights

- Opening one note no longer marks other notes' compacted comment snapshots as already imported.
- Keep snapshots pending when their Markdown content has not arrived yet, so comments can be imported after the note catches up.
- Receiving newer comment events no longer skips older snapshots that still need to be imported.

## Notes

- Automated regression coverage verifies snapshot replay across notes, newer events, and delayed Markdown delivery. Verification on two physical devices remains incomplete.
- This release does not guarantee recovery of comments already skipped by earlier versions.
- Release assets are limited to `main.js`, `manifest.json`, and `styles.css`.
