# 2.0.101

## What's new

- Run registered vault scripts directly from saved Aside comments, with live mention suggestions, persisted run history, retry support, and hardened launch checks that reject unregistered or escaped paths.
- Use Gemini CLI as a first-class local agent alongside Codex and Claude, including streamed replies, progress details, run metadata, cancellation, and clearer authentication errors.
- Work in a more predictable Index sidebar: Todo remains vault-wide, while List, Agent, Thought Trail, search, editing, deletion, restoration, and reordering become available after selecting a source file.
- Open an existing `🐰 Aside Index.md` immediately from the ribbon while its generated contents refresh in the background.
- See full note paths when hovering clickable Thought Trail nodes, use tighter mention and tag suggestions, and keep source-file actions consistently placed on Index cards.
- Keep published-file inventory and the generated public index synchronized when files are published, changed, or removed.

## Notes

- No data migration is required.
- Only uniquely registered direct vault scripts are highlighted and runnable; arbitrary Markdown file paths are not treated as scripts.
- Index Todo stays global. Select a file before using file-scoped Index tabs, search, or card mutations.
- Release artifacts remain limited to `main.js`, `manifest.json`, and `styles.css`.
