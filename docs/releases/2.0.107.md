# Release Highlights

Pin individual comment cards, navigate sidebar search matches, and expand anchored text previews. This release also improves reply placement, agent status, and publishing across synced devices.

## Highlights

- Pin individual comments and replies independently, with pin state preserved through sync.
- Navigate sidebar search matches with previous/next controls, Enter, and Shift+Enter. The first match is selected automatically, and hidden matches in anchored text are revealed.
- Preview up to six lines of anchored text, with Show more and Show less controls for longer passages.
- Insert replies immediately after the selected entry and keep sidebar cards steady while replies stream in.
- Show clearer comment loading states and search highlights.
- Prevent completed agent and script runs from returning to a stale running state after stored data reloads.
- Enable Scripts automatically when an available agent is detected.
- Restore publication links and actions from synced inventory, preserve explicitly configured Cloudflare Pages targets, and stop uploads when the target cannot be resolved.

## Notes

- Enabling publishing no longer invents a Pages project from the vault name. Configure an existing project or a publishing URL; conflicting project names and pages.dev URLs must be corrected before publishing.
- Release assets are limited to `main.js`, `manifest.json`, and `styles.css`.
