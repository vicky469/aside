## Goal

Return Aside publishing to a small public artifact publisher while retaining a useful generated inventory note.

## Architecture

The standalone publisher remains the only publishing runtime. It renders Markdown to HTML, carries supported HTML and PDF artifacts, deploys through Wrangler Pages, and records publish state in `public/index.md`.

`public/index.md` is fully generated by Aside. Aside may read the previous marked table formats during migration, but every subsequent write replaces the complete file with the shared Aside header image, caption, and inventory table. The index is owner-visible state, not an authentication or permission source.

All identity and private-site infrastructure is removed rather than disabled: no auth parser, permission model, OAuth routes, session cookies, private manifest, generated directory shell, D1 comment API, remote comment import, or private runtime modules remain.

## Publish Flow

Publishing a standalone Markdown, HTML, or PDF artifact:

1. Validates the existing publish feature flag and configured public root.
2. Generates or selects the public artifact.
3. Deploys the current public artifact snapshot through Wrangler Pages.
4. Records the artifact as published in `public/index.md` with its public URL and timestamp.

Unpublishing deploys the remaining artifact snapshot and records the target as unpublished with an empty URL and timestamp.

## Generated Index

The generated note has this shape:

```md
![Aside index header image](https://ichef.bbci.co.uk/images/ic/1920xn/p02vhq1v.jpg.webp)
<div class="aside-index-header-caption" style="...">Relativity (...)</div>

| path | published_url | type | status | last_published_at |
| --- | --- | --- | --- | --- |
| startup/tech stack.md | https://publish.example.com/public/startup/tech%20stack | file | published | 2026-08-06T08:00:00.000Z |
```

There are no HTML section markers, `permission_source`, or `auth.md` references in new output.

## Error Handling

- Publish validation and deployment errors preserve the current standalone publisher behavior.
- The index is updated only after a successful deployment.
- Existing legacy marked index tables are read for migration; unrelated old index prose is not preserved because Aside owns the complete generated file.
- Missing or malformed legacy index rows are ignored rather than deployed or interpreted as permissions.

## Out Of Scope

- Published directory navigation.
- Published Aside sidebar comments.
- Authentication or authorization.
- OAuth providers and session management.
- Cloudflare D1 comment storage.
- Private file or folder publishing.
